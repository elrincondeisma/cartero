# Teams and collaboration

## Workspaces

- Your **personal workspace** is just for you.
- **Team workspaces** are shared. Create one from the workspace switcher (top left) → *New team workspace*.

Each workspace has its own collections, environments, globals, mocks, monitors and run history.

## Invite people

**Settings → Members → Invite**: enter the email and role. They get a link (by email if an admin has set up email in **Administration → Email**; otherwise the link is copied to your clipboard so you can send it). It expires in 7 days.

| Role | Can |
|---|---|
| **Viewer** | See everything, send requests and run collections. Can't save changes |
| **Editor** | Also create, edit and delete collections, environments, mocks, monitors and docs |
| **Admin** | Also invite and manage members |
| **Owner** | Everything, including deleting the workspace and appointing admins |

## Real-time work

- **Presence**: the top bar shows who's online, and the tree shows a colored dot next to the request each person has open.
- **Live changes**: when someone saves, everyone sees it instantly. If you had that request open without changes, it updates by itself.
- **Conflicts**: if two people edit the same request, you'll get a warning when saving. **See theirs** or **overwrite** it.

## Comments

Open a request and click the comments icon (top right). Post with **Ctrl+Enter**. Comments can be **resolved** when they're no longer needed.

## Change history

In the same panel, **Changes** tab (or a collection's *Activity*): who changed what and when. Click **Restore** on any entry to go back to the previous state, even if a request or folder was deleted.
