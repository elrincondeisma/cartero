# Keyboard shortcuts

On Mac, use **⌘** instead of **Ctrl**. Press **?** anytime to see them.

| Shortcut | Action |
|---|---|
| **Ctrl + K** | Search requests, environments and actions |
| **Ctrl + T** | New request |
| **Ctrl + Enter** | Send the request |
| **Ctrl + S** | Save the request, collection or environment |
| **Ctrl + Alt + W** | Close the active tab |
| **Middle click** on a tab | Close it |
| **Right-click** on a tab | Close the others |
| **Ctrl + Space** (in scripts) | Autocomplete the `pm.*` API |
| **Ctrl + Enter** (in comments) | Post the comment |
| **?** | Show the shortcuts |
| **Esc** | Close dialogs and the guided tour |
| **← / →** (in the tour) | Previous / next step |
