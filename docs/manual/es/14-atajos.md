# Atajos de teclado

En Mac, usa **⌘** en lugar de **Ctrl**. Pulsa **?** en cualquier momento para verlos.

| Atajo | Acción |
|---|---|
| **Ctrl + K** | Buscar peticiones, entornos y acciones |
| **Ctrl + T** | Nueva petición |
| **Ctrl + Enter** | Enviar la petición |
| **Ctrl + S** | Guardar la petición, colección o entorno |
| **Ctrl + Alt + W** | Cerrar la pestaña activa |
| **Clic central** en una pestaña | Cerrarla |
| **Clic derecho** en una pestaña | Cerrar las demás |
| **Ctrl + Espacio** (en scripts) | Autocompletar la API `pm.*` |
| **Ctrl + Enter** (en comentarios) | Enviar el comentario |
| **?** | Ver los atajos |
| **Esc** | Cerrar diálogos y el recorrido guiado |
| **← / →** (en el recorrido) | Paso anterior / siguiente |
